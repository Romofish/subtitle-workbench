# AI 字幕人工审阅工作台：最终开发计划

> **当前实现状态：** 本地工作台已完成初始实现与工程验证；AI 翻译接口已实现，真实服务和模型留待配置。实测状态以 [工程验收记录](docs/acceptance.md) 和 [运行说明](README.md) 为准，不把离线测试记为真实服务或语言验收通过。

> **2026-10-23 范围追加：** 已接入一键本地转写，包括 whisper.cpp 与多语言模型安装脚本、无字幕媒体上传、单队列本地识别、进度/取消和自动建立待审阅项目。AI 翻译仍须单独配置。

> 文档版本：3.1 · 更新：2026-10-23\
> 适用环境：Apple Silicon Mac、本地网页、单用户。\
> 当前范围：本地字幕审阅、转写、可选翻译接口及独立下载脚本；剪辑、复杂样式与压制交给外部工具。\
> 执行依据：本文是后续开发的唯一主计划；[工具使用补充](free-tools-subtitle-workflow-plan.md)说明外部工具与文件交接。

## 1. 已确定的方向

复用成熟工具处理下载、按需剪辑、语音识别、复杂字幕排版和视频压制；自研集中在 **AI 字幕人工审阅工作台**：看视频、听原音、核对原文与中文、采用 AI 候选、安全保留人工修改，再导出字幕。

首版优先验证审阅、人工修改保护和字幕同步；剪辑器、烧录器与全模型评测不属于当前实现范围。

| 环节 | 承担方 | 与工作台的交接 |
|---|---|---|
| 下载与平台字幕 | 现有 yt-dlp 下载脚本 | 媒体、独立字幕、来源清单 |
| 按需剪辑 | 已选用的外部剪辑工具 | 一份定剪媒体及对应时间轴的字幕 |
| 缺字幕时的 ASR | 工作台调用本机 whisper.cpp；外部识别可作备选 | 自动建立待审项目，保留原始识别结果与工具模型记录；也可导入 SRT / VTT |
| AI 翻译与人工审阅 | 自研工作台 | 原文、中文、候选、修订和审阅状态 |
| 高级样式与发布 | 外部字幕编辑及压制工具 | 审定字幕；生成带固定字幕的发布视频或软字幕收藏版 |

非 AI 环节继续使用免费软件，不要求付费插件或付费导出。云端 AI 可产生费用，服务、模型、外发范围和费用边界在 W2 配置时确定；本轮不调用收费服务。

## 2. 素材路径与时间轴约定

日常流程：**下载或本地导入 → 按需在外部定剪 → 选择可用原语字幕或本地识别 → 工作台翻译与人审 → 导出字幕 → 外部排版和发布。**

- 已有可用原语字幕：先检查语言、同步和明显错误，可跳过 ASR；平台普通字幕不等于已证明准确或官方。
- 只有平台自动字幕：可直接作为待审原文，不强制重新识别；质量不够时再从原音识别。
- 泰语音频只有英文字幕：允许英文转译，明确标为中间语参考；不能冒充泰语逐字原文。
- 字幕已印在画面中：不等于可提取文字轨；首版不做 OCR，按需从原音识别。
- 不固定增加“分离音频”步骤：识别工具可读视频时直接使用，需要独立音频时再提取。

**首版每个项目只绑定一份固定媒体时间轴和一个选定音轨。** 所有字幕时间为该媒体播放起点起算的整数毫秒，采用 `[start_ms, end_ms)`；不建立原片与剪辑成片间的 EDL 映射。

需要剪辑时先定剪，再导入工作台；原片字幕须由外部流程重映射或重新生成并检查。以后更改剪辑、变速、替换内容，建立新项目或新媒体版本并重新核对同步，不能仅改文件名继续套用旧时间。只做无内容变化的重新封装，也要验证时长、起点和同步。

原始下载文件与字幕始终保留；“原片”不等于上传者母版，也不承诺平台流数学无损。浏览器无法播放所选媒体时，按需生成带来源引用的预览副本，保持时间对应；预览副本不替代原片或外部发布的媒体来源。方向、色彩及首中尾同步须检查。

## 3. 下载交接 D0

下载脚本已完成本地单元和真实工具离线集成验证，并针对实际平台 429 故障分离媒体与字幕下载。新脚本未再次请求平台验证是否解除限制。具体文件格式、使用方式、限制与证据见 [下载器说明及验收记录](../../downloader.md)。D0 可独立使用，不阻塞本地文件导入。

| 项目 | 要求 |
|---|---|
| 字幕语言 | 保留原有中文、英文选择，加入泰语；记录实际请求及获取到的语言 |
| 轨道区别 | 区分平台普通字幕、自动字幕；能识别自动翻译时注明，不能确认的写 `unknown` |
| 来源语义 | “平台普通字幕”不自动标为官方或原语；语言代码、标题只能作为证据的一部分 |
| 文件保留 | 媒体与独立字幕一并保存；保留后续可审查的来源信息，不要求再次从内嵌轨提取 |
| 状态报告 | 分开报告媒体是否下载成功、字幕是否可用、字幕是否下载成功、来源记录是否完整 |
| 空字幕与失败 | 无可用字幕是正常分支；有轨道但下载失败是失败状态，不混称“没有字幕” |
| 追溯 | 清单含源 URL / 平台 ID、获取时间、工具版本、实际输出文件及字幕来源证据；不写入凭证或签名下载 URL |

交接清单表达媒体与字幕的类型、语言和来源，但不要求固定拆出独立音频文件。脚本用 ffprobe 记录下载媒体中的视频、音频和内嵌字幕轨；工作台支持本地媒体导入，内嵌文字字幕可先由外部工具提取。每次来源记录留有历史副本；视频 ID 命名、旧文件保留和未完成分片续传边界见下载器说明。

工作台以后可读取清单辅助填写来源；清单缺失时仍允许本地文件导入，来源记为未知或用户声明，并保留声明依据。

## 4. 首版工作台范围

### 必须交付

| 能力 | 最低可用行为 |
|---|---|
| 导入 | 本地视频或音频 + SRT / VTT；也允许无媒体的字幕编辑；导入外部 ASR 文件 |
| 本地识别 | 无字幕媒体上传、选定音轨、原语识别、单队列进度/取消；完成后建立独立待审项目 |
| 审阅 | 原文与简体中文双栏；点句定位、逐句循环播放、可调前后余量、键盘操作 |
| 编辑 | 修改原文、译文和时间；搜索、拆分、合并、撤销；显示未审、待复核、已审状态 |
| AI 辅助 | Responses API 配置接口；只读上下文、版本化术语表；局部重译、候选对比、明确采用；真实服务待配置 |
| 风险提示 | 听不清、疑似错词、专名和数字、漏译、超长文本、非法或越界时间；提示不冒充事实 |
| 保存 | 自动保存状态可见；项目重开、修订追溯、冲突保护、任务中断恢复 |
| 导出 | 原文、中文、双语 SRT / VTT；可恢复项目包与来源记录；外部工具交接说明 |

不在首版做：剪辑 EDL、多来源视频拼接、视频烧录器、复杂 ASS 样式编辑、任意 ASR 引擎/模型切换管理、说话人分离、全模型评测、批量流水线、账号与多人协作、桌面壳。已提供固定 whisper.cpp 引擎与模型的安装脚本。

首版建议验证规模为一份不超过 60 分钟的媒体和 3,000 条字幕；这是计划中的验证范围，不是已测性能承诺。先使用真实短素材跑通，再检查长项目保存和交互。

## 5. 最小技术架构

| 组件 | 选择与职责 |
|---|---|
| 前端 | React + TypeScript + Vite；播放器、原文中文双栏、候选和审阅列表 |
| API | FastAPI + Pydantic；文件导入、字幕操作、版本校验与导出 |
| 存储 | SQLite + 本地文件；项目、字幕、修订、候选、术语、任务与导出快照 |
| 任务 | 一个轻量独立 Python worker；本地转写、分批翻译、取消与有限重试；不引入分布式队列 |
| 媒体辅助 | ffprobe 探测；必要时由 FFmpeg 生成预览副本；不承担剪辑和发布渲染 |

API、界面和 worker 共享明确的数据契约。选用独立虚拟环境和依赖锁，不沿用系统 Python 版本推定兼容性。本地服务仅监听回环地址；外部 AI 密钥由配置注入，不存入项目包和普通日志。

任务状态至少区分等待、运行、完成、失败、取消；保存已提交批次，重试不能制造重复候选或覆盖编辑。W1 就落实保存和版本保护，不能推迟到 AI 接入之后。

## 6. 关键数据契约与人工修改保护

### 项目、素材与字幕

| 对象 | 关键字段与不变量 |
|---|---|
| `project` | `project_id`、`schema_version`、`document_revision`、媒体引用、目标语言、术语版本 |
| `media` | `media_id`、文件哈希、时长、选定音轨、来源；预览另存引用和时间对应关系 |
| `track` | `track_id`、语言、来源类型、原始文件哈希、媒体时间轴引用；未知来源不可伪装已确认 |
| `segment` | 稳定 `segment_id`、`start_ms` / `end_ms`、原文 / 中文、`revision`、`source_revision`、审阅状态 |
| `candidate` | 目标 ID、请求基准版本、原文 / 上下文 / 术语指纹、服务与模型、候选内容、错误或疑点 |
| `revision` | 修改前后值、操作者、原因、时间、事务 ID；拆分合并保留父 ID 关系 |
| `export` | 导出 ID、冻结的项目版本、媒体哈希、输出文件哈希、字幕 ID 映射及导出模式 |

来源类型表达平台普通字幕、平台自动字幕、自动翻译、本地 ASR、外部 ASR、人工导入和未知；“人工导入”描述导入方式，不证明内容由人撰写。语言、来源类型与用户可信度评价分开记录。

### 写入与候选采用规则

1. 显示序号不作主键；排序或调时间不改变 `segment_id`。所有修改携带 `base_revision`，版本过期须冲突提示，禁止后到写入静默覆盖。
2. 原文变化递增 `source_revision`；保留旧译文并标记过期，取消该句已审状态。时间变化使同步审阅失效；上下文或术语变化标记受影响候选过期，并提示相关译文复核。
3. AI 请求记录原文、译文、上下文和术语的基准版本。当前实现将所有翻译结果保存为候选；采用必须经过明确操作和版本复核，不自动填入或覆盖中文。
4. 人工编辑过的中文不被自动结果覆盖。候选采用是明确操作，提交时再次检查当前版本，生成新修订；丢弃候选不删除历史人工稿。
5. LLM 对“听错原文”的判断只提供候选和理由，不能自动改写原文或时间。需听音确认；没有音频证据时明确不确定。
6. 拆分 / 合并生成新 ID，记录父 ID，原条目软删除；时间和文字分配由人确认，不按字符比例伪造语义对齐。旧 ID 的在途任务失效，结果只能存档，不能写入新条目。
7. 拆分 / 合并、撤销和采用候选均为原子事务。撤销检查全部关联条目的版本，有后续冲突时拒绝部分恢复；修订恢复写新版本，不回退版本号。
8. 每次影响内容、顺序、审阅或导出的修改递增 `document_revision`；导出绑定冻结快照，导出时继续编辑不改变该次文件。

### 外部导出再回导

SRT 的序号和 VTT 的可选 ID 不能代替工作台身份；普通字幕文件通常不能携带完整修订史。

- 项目包包含 `schema_version`、媒体指纹、稳定 ID、修订、术语和候选；可重新关联缺失媒体，但哈希不匹配不得自动认作同一时间轴。
- 字幕导出附带清单，记录冻结版本、字幕 ID 与条目对应关系、文件哈希。外部修改后回导，先生成预览和差异，不直接覆盖。
- 外部文件保留可验证身份且映射唯一时，形成待采用变更；若重排、拆分合并、丢失清单或对应关系有歧义，导入为新参考轨并分配新 ID，由人工确认合并。
- 时间和文本相似度只能建议匹配，不能凭行号或时间自动认定身份。先前人工稿和审阅历史保留；外部软件工程和撤销栈不要求互通。

## 7. AI 接入与审阅体验

W2 只接一个真实服务，模型配置化，不把截图里的模型名称当作最终选型。请求包含选中句的稳定 ID 和版本、只读邻近上下文、术语表、目标语言及翻译要求；响应按 ID 校验，拒绝缺失、重复或未知 ID 的自动写入。

AI 输出不允许私改时间轴、增删字幕或改写未选中的上下文。泰英混说保留原语和专有名词；中文不确定时标记疑点，不补编听不见的信息。术语变更和局部重译可追溯到采用版本。

主界面优先呈现播放器、逐句双栏与当前候选；审阅队列可筛选待审、原文已变、时间需查和术语疑点。循环播放带前后文余量，修改时不丢焦点，保存状态和服务错误可见。未审草稿允许导出，但需明确状态，不能标为已审定成品。

无密钥、未选模型、服务故障或仅有 mock 时，AI 状态为“待配置 / 不可用 / 待验收”，不计真实翻译通过；本地编辑、保存和字幕导出仍能使用。先明确本次发送的文本和上下文，不默认上传媒体。

## 8. 分阶段交付与出口条件

| 阶段 | 实施内容 | 出口条件 |
|---|---|---|
| D0 下载交接（工程测试通过） | 泰语字幕、来源和输出清单、分项状态；媒体与字幕失败隔离 | 单测与真实工具离线集成通过；平台限流是否解除不作保证 |
| W1 审阅保存骨架（工程测试通过） | 本地媒体、SRT / VTT、双栏、逐句回放、编辑与拆分合并、基础字幕导出、自动保存和重开 | 本轮用用户同意的合成素材完成浏览器闭环与数据保护验证；真实素材同步另验 |
| W2 真实 AI 辅助（接口就绪，用户选择稍后配置） | 一个服务、上下文与术语、局部重译候选、版本校验、取消重试 | 离线保护测试通过；真实调用、模型及费用配置尚未启用，不计真实翻译通过 |
| W3 外部交付验收（工程部分通过） | 完整导出与参考轨回导、项目包恢复、外部工具安装、规模验证 | 导出恢复、3,000 条规模与工具安装已验证；真实语言及发布成品待后续素材 |
| 本地识别追加（工程测试通过） | 固定引擎/模型安装、异步转写、取消、独立待审项目 | 短音频和完整视频流程已跑通；语义与逐句时间仍待人工复核 |

阶段编号代表依赖顺序，不是工期承诺。D0 与 W1 可独立使用；W2 依赖 W1 的数据保护，W3 依赖可审阅可导出的项目。工程证据与未验项详见验收记录。
