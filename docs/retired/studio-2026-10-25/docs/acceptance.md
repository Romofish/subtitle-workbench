# 初始工作台工程验收

记录日期：2026-10-22 至 2026-10-23（Asia/Shanghai）。以下为开发环境的历史验收摘要；公开仓库不包含个人媒体、项目数据库、恢复字幕、浏览器下载文件或完整执行日志。AI 翻译默认未配置，工程测试不等于真实服务或语言质量通过。

## 已有工程证据

2026-10-22 初始基线自动化检查为 40 项通过。2026-10-23 扩展本地 ASR 与下载器 429 修复后，`PYTHONPATH=backend .venv/bin/python -m pytest backend/tests tests/test_downloader_manifest.py -q` 为 **58 项通过**（14 项工作台后端、15 项 AI 数据保护、13 项 ASR、16 项下载器；约 19 秒）。第三方 TestClient 的弃用提示不影响通过结果。

公开发布准备时再次运行上述 58 项测试、7 个真实 yt-dlp / FFmpeg 离线集成场景、前端正式构建与 Bash 语法检查，全部通过。集成场景包含本地 HTTP 429，不代表平台已解除限流。

- 本机：macOS 15.8，arm64；隔离环境 Python 3.13.7；Node 24.5.0。详细依赖见 `backend/requirements.lock` 与 `frontend/package-lock.json`。
- UTF-8 / BOM、中泰英 SRT / VTT 解析、非法时间拒绝、双栏文本与时间编辑、稳定 ID、原文变更后的译文复核、邻近上下文失效。
- 同一字幕的旧版本修改被 409 拒绝；拆分、合并、候选采用和撤销以 SQLite 事务提交。撤销发现后续冲突时不恢复其中一部分。
- AI 离线测试覆盖人工编辑期间迟到结果、上下文/术语变更、目标软删除、运行中取消、重复提交、worker 中断恢复、响应 ID 缺失/重复/未知、输出不完整与有限重试。测试使用显式 mock，不访问收费接口。
- 采用候选后的撤销恢复原稿与候选状态，版本号继续增加；过期候选保留，但不能直接写入当前稿。
- 原文、中文、双语的 SRT / VTT 六种导出可回读；导出清单包含冻结版本、文件哈希及字幕 ID 映射。外部修改文件先显示差异，另建参考轨。
- 项目包恢复保留人工文本、ID 和历史；媒体重新关联校验 SHA-256，不同内容会被拒绝。HTTP byte-range 支持播放器跳转。
- SQLite backup API 一致性备份经过独立数据库恢复、`integrity_check` 及人工文本核对。
- API 仅在回环地址监听，有 Host / Origin 校验；启动器同时管理 API 与独立 worker，关闭后端口已实测释放。

## 真实浏览器操作验收

使用 Playwright 驱动本机 Chromium，对独立临时数据目录进行操作。以下流程已通过：

- 通过导入弹窗选择 SRT 和 24 秒 MP4，播放器读取时长 24 秒、解码就绪；关闭循环后在当前句结束加余量处暂停（本次 3.387 秒）。
- 在中文编辑器输入后自动保存，刷新页面重开内容一致。
- 人为延迟一次保存响应 1 秒，期间继续输入最终稿并切换下一句：最终稿保留并提交。
- 模拟另一窗口先保存同一句，页面收到预期 409，保留本地输入并显示当前服务端原文、中文及时间；用户明确选择后再保存。
- 弹窗拆分后 8 条变 9 条，事务撤销恢复 8 条；合并后 7 条，撤销恢复 8 条。
- 从界面下载字幕清单 ZIP、项目包和全库备份；文件哈希一致，SQLite 完整性检查通过。
- 从界面恢复项目包，原人工稿保留；媒体缺失提示正确，重新选择原 MP4 后哈希校验通过并恢复播放。
- 术语保存升至 v1，明确确认已审，AI 服务继续显示待配置。
- 3,000 条纯字幕项目导入并呈现第一页 100 行，本次约 113 ms；全局搜索可定位第 3,000 条，编辑保存通过。该测量是单次交互样本。
- 1440、1280 和 720 像素视口没有页面横向溢出；控制台只有人为冲突测试产生的预期 HTTP 409，没有未捕获脚本异常。

浏览器破坏性测试使用独立临时数据库；合成演示文件位于 `examples/`。验收截图及浏览器下载核对文件仅保留在验证环境，不随公开仓库发布。

构建验证：`npm run build`（TypeScript + Vite）通过；`npm ls --depth=0`、`pip check` 通过。默认服务入口 `http://127.0.0.1:8765`，前端页面已实际打开验证。

## 数据库恢复操作

日常优先使用界面的项目包恢复。完整数据库恢复用于本机灾备：

1. 停止工作台，保留原 `.workbench-data/` 目录；不要覆盖运行中的数据库。
2. 建立一个新的数据目录，把下载的 SQLite 备份放入该目录并命名 `workbench.sqlite3`。
3. 媒体文件不包含在数据库备份中。保留原数据目录的 `projects/` 媒体，或在新环境为每个项目重新关联哈希一致的原文件。
4. 在 `.env` 中将 `SUBTITLE_DATA_DIR` 设为新目录的绝对路径，启动并核对项目、修订和媒体。
5. 确认恢复完整后再自行决定旧目录的保留策略。项目不提供自动清理原片与修订的功能。

## 明确边界

- 本轮不启用收费 AI。真实服务连接、所选模型效果、费用与泰英语言质量验收，按用户决定留待配置后进行。
- 合成测试视频只有测试图与低音量正弦音，没有真实人声；不计入 ASR 或语言质量验收。
- 首版是字幕文本审阅工具。VTT 样式、区域、定位和高级 ASS 排版不在往返保真范围；原始字幕始终另存。
- 外部改字、拆分或重排后无法可靠证明字幕身份时，当前实现固定走参考轨。已实现差异预览，尚未提供基于可验证身份的自动待采用补丁流程。
- 一个项目绑定一个媒体指纹及一个选定音轨。需更换剪辑、变速或内容时建立新项目；可选预览不替代发布母版。方向、色彩与真实素材首中尾同步仍需人工检查。
- 2026-10-23 用户追加本地 ASR 后，已安装固定 whisper.cpp 引擎与多语言模型；不开发剪辑器、烧录器、桌面壳、多人协作或批量生产流水线。
- 导出时字幕内的空白行会规范化为一个换行，避免破坏 SRT/VTT cue 分隔；规范化记录在逐句导出清单中，数据库里的人工原稿保持不变。

## 2026-10-23 本地转写追加验收

用户明确选择“接入工作台的一键本地转写”，AI 翻译仍未配置。模型、源码与构建工具来源固定，安装脚本校验 SHA-256；模型实际 574,041,195 字节。whisper.cpp 1.9.5 为 arm64 静态构建，Metal 内核内嵌，运行只依赖 macOS 系统库。安装清单：`tools/asr/manifest.json`。

- 后端 13 项 ASR 测试覆盖异步排队、准备缺失、空媒体、错误音轨、无有效字幕、取消排队/运行/提交竞态、静默子进程停止、worker 中断恢复、重复领取和已完成人工稿保护。
- 实际 FFmpeg 双音轨测试保留指定音轨的 1.25 秒前导空白；容器起点 0 秒与 5 秒均对应同一媒体时间轴，不把识别 WAV 的起点错套到视频。
- 真实 30 秒泰语片段：直接 CLI 首次含 Metal 初始化约 16 秒；通过浏览器上传、排队、自动建项目约 7.1 秒。结果 17 条，检测 `th`，原语转写 `translate=false`；不是人审准确率验收。
- 真实浏览器：缺模型时开始按钮禁用，安装后重新检查启用；上传后返回 202，后台完成不自动切换当前项目；明确点“打开项目”后显示本地 ASR、17 条待复核、中文为空。
- 新项目中人工输入、自动保存、刷新恢复、双语 ZIP 导出通过；音频播放器就绪并正确读取 30 秒时长。取消请求后任务 cancelled，无半成品项目。720 像素下弹窗和页面无横向溢出。
- 测试数据位于独立临时目录，未写入正式项目；正式服务更新前已创建一致性 SQLite 备份。个人测试目录与备份不随公开仓库发布。
- 下载器 16 项单测及 7 项真实工具离线集成通过；本地 HTTP 429 场景确认保留媒体和首条成功字幕，不重试 429，剩余轨不发请求。新脚本已与桌面入口同步，旧版备份保留。
- 一份约 12 分钟的实际视频通过界面提交，约 113.3 秒完成本地转写，生成 257 条待复核原语字幕，另存 217 条英文参考轨；原始下载未改动。浏览器直接解码 MKV，readyState=4，时长正确且无媒体解码错误。字幕语义及逐句时间尚未人工核验，尤其开场音乐附近的句首时间需复核。

原始转写验证摘要含本机路径与任务记录，仅保留在验证环境；此处公开匿名汇总。

模型生成内容一律为待审稿。泰英混说、说话人、人名、静音幻觉和真实整片同步仍须人工核对；本轮未调用收费翻译接口。
