# 合成测试素材

2026-10-25 起按 [SE 主流程计划](../docs/se-workflow-plan.md)使用现成工具；本目录保留用于字符、时间与播放检查。

`timing-check.mp4` 是 FFmpeg testsrc2 与低音量正弦音生成的 24 秒测试视频；没有真实人声。`timing-check.srt` 包含中、泰、英文本，供导入、定位、编辑、保存和导出验证。字幕与视频中的人声没有对应关系。

这些文件不代表 ASR、翻译准确率、真实混说或发布成片验收。泰语文本仅是字符与编辑测试用例。真实语言质量与首中尾同步需要用户提供的真实素材及有语言能力的人复核。

可在 Subtitle Edit 中分别打开视频与字幕，检查字体、定位和编辑后另存；不要覆盖样例原件。这里没有人声，不能用于验证 ASR 引擎或多人识别。

旧 Studio 的演示操作已归入 [退役运行说明](../docs/retired/studio-2026-10-25/README.md)，不再作为日常启动流程。
